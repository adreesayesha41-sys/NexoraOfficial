# NEXORA OFFICIAL
1. Create a free project at supabase.com, then run supabase.sql in the SQL Editor.
2. Supabase > Authentication > Users > Add user (your admin email + password). Turn off new sign-ups in Auth settings.
3. In Netlify > Site settings > Environment variables add VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY (Supabase > Project Settings > API), then redeploy.
4. Set WHATSAPP and INSTAGRAM in src/App.jsx.
5. Admin page: /admin
